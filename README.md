# Rayker Riz Light Project

A small, beginner-friendly website about the Rayker Riz game.

## Pages

- `index.html` is the home page with a short introduction, trailer, facts, and gallery.
- `items.html` shows game items, combat tips, and multiplayer items.
- `map.html` shows the world map, NPCs, dungeon route, boss, and current build details.

## Files

- The `.html` files hold the page content.
- `style.css` controls the colors and layout.
- `script.js` shows a new game fact each time its button is clicked.
- `assets/` contains the pictures used by the pages.

## Open the website

Open `index.html` in a browser to look at the pages. For the embedded YouTube trailer, open the folder with a local web server such as VS Code Live Server. The trailer section also has a link to watch the video directly on YouTube.

The project uses HTML, CSS, and a small amount of JavaScript. It does not need Java or a package installation.
